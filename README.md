# SAMapStudio Releases

## English

Public downloads for SAMapStudio, the standalone map editor for SA-MP and open.mp on Windows x64.

### Downloads and updates

Get published builds from [Releases](https://github.com/Knife105/SAMapStudio-Releases/releases). Each release provides the compiled application ZIP and `update-manifest.txt` with its signed version, size and SHA-256.

The editor checks for updates at startup and every 24 hours. Open `About... > Updates...` for manual checks and verified downloads. The dialog opens centered, shows the animated logo, and adapts to smaller screens. Update messages use English first, followed by Spanish.

The application checks public downloads without a GitHub token and verifies the digital signature before accepting an update. Automatic installation with a controlled restart is the next stage.

### Source code and user data

This repository is for distribution only. The application source is maintained separately and remains private. Source files, debug symbols, private signing keys, credentials, game files and personal projects are not included.

GitHub automatically offers “Source code” archives for release tags. Here they contain only this distribution repository, not the editor's source code.

Keep your existing `SAMapStudioData` folder when updating: it contains recovery sessions, bookmarks, collections and preview images.

## Español

Descargas públicas de SAMapStudio, el editor de mapas independiente para SA-MP y open.mp en Windows x64.

### Descargas y actualizaciones

Descarga las versiones publicadas desde [Releases](https://github.com/Knife105/SAMapStudio-Releases/releases). Cada versión incluye el ZIP del programa compilado y `update-manifest.txt` con su versión, tamaño y SHA-256 firmados.

El editor busca actualizaciones al iniciar y cada 24 horas. Abre `About... > Updates...` para buscar manualmente y descargar paquetes verificados. El diálogo abre centrado, muestra el logo animado y se adapta a pantallas pequeñas. Los mensajes muestran inglés primero y español después.

El programa consulta descargas públicas sin un token de GitHub y comprueba la firma digital antes de aceptar una actualización. La instalación automática con cierre y reinicio controlados corresponde a la siguiente etapa.

### Código fuente y datos personales

Este repositorio solo distribuye el programa. Su código fuente se mantiene separado y privado. No incluye código, símbolos de depuración, claves privadas de firma, credenciales, archivos del juego ni proyectos personales.

GitHub ofrece automáticamente archivos “Source code” para cada tag. Aquí contienen únicamente los archivos de este repositorio de distribución, no el código del editor.

Conserva tu carpeta `SAMapStudioData` al actualizar: contiene recuperación, vistas de cámara, colecciones e imágenes de vista previa.
