# SAMapStudio Releases

Public downloads and signed update metadata for SAMapStudio, the standalone map editor for SA-MP and open.mp on Windows x64.

## Downloads

Download published versions from [Releases](https://github.com/Knife105/SAMapStudio-Releases/releases).

Each release contains the compiled application ZIP and update-manifest.txt with its signed version, size and SHA-256. The editor checks public downloads without a GitHub token and verifies the digital signature before accepting an update.

## Source code and user data

This repository is for distribution only. The application source code remains private and is maintained separately. Source code, debug symbols, private signing keys, credentials, game files and user projects are not included in the distribution.

GitHub automatically offers Source code archives for release tags. Those archives contain only this distribution repository, not the editor source code.

Keep your existing SAMapStudioData folder when updating: it contains your recovery sessions, bookmarks, collections and preview images. The current update stage checks versions and downloads verified packages; automatic installation with a controlled restart is the next stage.
